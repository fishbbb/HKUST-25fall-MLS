# 第 4 课：搭一个 CIFAR-10 的卷积神经网络

## 这一课在整门课的位置

数据已经能按 `(N, 3, 32, 32)` 的批次读出来。这一课把吃下这种批次、吐出 `(N, 10)` logits 的模型写出来。写完之后用一个假批次把每一块的形状打出来，确认空间尺寸是按你的设计在缩小，而不是靠运气撞上的。

## 学完你要能说出的话

- 自己的模型是一个继承 `nn.Module` 的类。层在 `__init__` 里创建，数据在 `forward` 里按顺序流过这些层。
- 调用 `model(images)` 时，PyTorch 执行的就是 `forward`。
- 最后一层是 `Linear(256, 10)`，输出 10 个 logits，不在这里做 softmax。
- 这个小网络把 32×32 的特征图池化三次，变成 4×4，再收成每个通道一个数，最后映射到 10 类。

## 网络里每一层在干什么

**卷积 `Conv2d`。** 用一组小的滤波器在图上滑动，找局部图案。第一块的输入通道是 3，因为图是彩色的。输出通道 32，表示这一层同时学 32 种图案。卷积核大小是 3×3。`padding=1` 在四周补一圈 0，让 3×3 卷积之后高和宽仍是 32。不补的话，高宽会变成 30，后面的尺寸你就得重新算。

**批归一化 `BatchNorm2d`。** 在一个批次内部，把每一个通道的激活值平移缩放到比较稳定的范围，再用两个可学习的参数拉回合适的尺度。它让更大学习率也能训得动。这个层有一个训练状态和一个评估状态：训练时用当前批次的均值和方差，并更新一份滑动平均；评估时使用那份滑动平均，不再用当前批次。所以第 6 课必须切换 `model.train()` 和 `model.eval()`。

**ReLU。** 负数变成 0，正数保持。没有这种非线性，很多层叠在一起仍然等价于一层大的线性变换，表达能力不够。

**最大池化 `MaxPool2d(2)`。** 每 2×2 的窗口只留下最大的那个数，高和宽各除以 2。它降低后面的计算量，也让特征稍微不怕图案挪动一两个像素。三次池化之后，32 变成 16、8、4。

**自适应平均池化 `AdaptiveAvgPool2d(1)`。** 不管前面还剩 4×4 还是别的尺寸，每个通道都平均成 1 个数。128 个通道就得到 128 个数。这样做的好处是：分类头的 `Linear` 输入维度固定是 128，你以后若改输入分辨率，不用去改全连接层的输入大小。

**Dropout。** 训练时按概率把一部分激活随机置成 0。`Dropout(0.5)` 大约丢掉一半，`Dropout(0.3)` 大约丢掉三成。网络就不能死记某几个特别大的激活。PyTorch 在训练时把留下来的激活乘上 `1 / (1 - p)`，这样它们的期望尺度不变。评估时 Dropout 变成恒等映射，所有激活原样通过，不再乘这个系数。所以训练和评估必须切换 `model.train()` 和 `model.eval()`。Dropout 是第 7 课要讲的正则手段，这一课先把它放进结构，让你看到它住在分类头里。

**全连接 `Linear`。** `Linear(128, 256)` 把 128 个数映射成 256 个数，`Linear(256, 10)` 再映射成 10 个 logits。10 就是类别数。

## 完整的模型

```python
import torch
from torch import nn


class CifarCNN(nn.Module):
    def __init__(self):
        super().__init__()

        # 一个 block：两层 3×3 卷积，每层后面接 BatchNorm 和 ReLU，最后池化把高宽减半。
        # in_ch 是这一块吃进来的通道数，out_ch 是吐出去的通道数。
        def block(in_ch, out_ch):
            return nn.Sequential(
                nn.Conv2d(in_ch, out_ch, kernel_size=3, padding=1),
                nn.BatchNorm2d(out_ch),
                nn.ReLU(),
                nn.Conv2d(out_ch, out_ch, kernel_size=3, padding=1),
                nn.BatchNorm2d(out_ch),
                nn.ReLU(),
                nn.MaxPool2d(kernel_size=2),
            )

        # 三块叠起来：3 -> 32 -> 64 -> 128 个通道。
        # 空间尺寸：32 -> 16 -> 8 -> 4。
        self.features = nn.Sequential(
            block(3, 32),
            block(32, 64),
            block(64, 128),
        )

        # 每个通道收成 1 个数，输出形状 (N, 128, 1, 1)。
        self.pool = nn.AdaptiveAvgPool2d(output_size=1)

        # 分类头。Dropout 的比例只在 model.train() 时生效。
        self.classifier = nn.Sequential(
            nn.Dropout(p=0.5),
            nn.Linear(128, 256),
            nn.ReLU(),
            nn.Dropout(p=0.3),
            nn.Linear(256, 10),
        )

    def forward(self, x):
        # x: (N, 3, 32, 32)
        x = self.features(x)       # (N, 128, 4, 4)
        x = self.pool(x)           # (N, 128, 1, 1)
        x = torch.flatten(x, 1)   # 从第 1 维开始拉平，保留 batch 维：(N, 128)
        return self.classifier(x) # (N, 10) logits
```

`super().__init__()` 让 `nn.Module` 完成它自己的登记工作。你把层存成 `self.features` 这种属性之后，模块才会把里面的权重算作自己的参数。如果只是在 `forward` 里临时 `nn.Conv2d(...)` 一个层，那个层的权重不会被优化器看到，也存不进 `state_dict`。层必须在 `__init__` 里创建并赋给 `self`。

`torch.flatten(x, 1)` 的 `1` 是起点。第 0 维是批次，必须留下，否则 64 张图会被拉成一根长向量。

## 把形状走一遍

不要只相信注释里的数字。用一个批次为 2 的随机张量，把三个 block 的输出形状打出来。

```python
torch.manual_seed(42)
model = CifarCNN()
model.eval()  # 这里只看形状，关掉 Dropout 的随机置零，数值更稳定。

fake = torch.rand(2, 3, 32, 32)

with torch.no_grad():
    h = fake
    for index, block in enumerate(model.features):
        h = block(h)
        print(f"block {index}", tuple(h.shape))
    h = model.pool(h)
    print("pool", tuple(h.shape))
    h = torch.flatten(h, 1)
    print("flat", tuple(h.shape))
    logits = model.classifier(h)
    print("logits", tuple(logits.shape))
```

你应当看到：

```text
block 0 (2, 32, 16, 16)
block 1 (2, 64, 8, 8)
block 2 (2, 128, 4, 4)
pool (2, 128, 1, 1)
flat (2, 128)
logits (2, 10)
```

`torch.no_grad()` 表示这段只是查看，不要为了它建计算图。第 6 课测评时会正式用它。

直接调用整网应当得到同样的 logits 形状：

```python
with torch.no_grad():
    out = model(fake)
print(out.shape)  # torch.Size([2, 10])
```

## 权重长什么样

参数是卷积核、BatchNorm 的缩放和平移、全连接的矩阵和偏置。Dropout、ReLU、池化没有可学习的权重。

```python
total = 0
for name, param in model.named_parameters():
    count = param.numel()
    total += count
    print(f"{name:30s} {tuple(param.shape)!s:18s} requires_grad={param.requires_grad}")
print("total parameters", total)
```

`numel()` 是这个张量里元素的个数。`requires_grad=True` 表示第 5 课的反向传播会给它写梯度，Adam 会更新它。打印结果里你应当能找到类似下面的名字：

- `features.0.0.weight`：第一块里第一层卷积的核，形状 `(32, 3, 3, 3)`，意思是 32 个输出通道、3 个输入通道、3×3 的核。
- `classifier.1.weight`：第一个全连接层，形状 `(256, 128)`。
- `classifier.4.weight`：最后一层，形状 `(10, 256)`。

这些名字就是以后 `state_dict` 里的键。加载权重时，键必须对得上，所以保存和加载要用同一个类结构。

## 最后一层为什么停在 logits

softmax 会把 10 个实数变成 10 个正数并且加起来等于 1，看起来像概率。`CrossEntropyLoss` 内部已经包含了 log_softmax。你若先 softmax 再送进这个损失，等于做了两次，数值还会更不稳定。

因此 `forward` 的返回值就叫 logits。想看概率时再单独做：

```python
probabilities = torch.softmax(logits, dim=1)
print(probabilities[0].sum().item())  # 应当非常接近 1
```

预测类别时连 softmax 都不需要。softmax 不改变大小顺序，`argmax` 在 logits 上和在概率上的结果一样。训练循环里保持用 logits。

## 调用模型时实际发生的事

`logits = model(images)` 看起来像函数调用。`nn.Module` 定义了这个调用：它会先走一些钩子，再进入你写的 `forward`。你应当调用 `model(images)`，而不是在训练代码里写 `model.forward(images)`。平时两者结果相同，但绕过调用会跳过模块约定的那些钩子。

## 课后练习

**口述 1.** 从 `(64, 3, 32, 32)` 讲到 `(64, 10)`。说出三次池化之后的高宽，以及拉平之后交给第一个 `Linear` 的特征个数。

**口述 2.** 为什么层要写在 `__init__` 里，而不是写在 `forward` 里面临时创建？

**代码.** 建一个 `CifarCNN`，用批次为 8 的随机输入，打印 `out.shape`，并断言它等于 `(8, 10)`。再打印最后一层权重的形状。

**思考.** 如果把三块的通道改成 16、32、64，分类头要改哪里？`AdaptiveAvgPool2d(1)` 之后拉平的长度变成多少？如果有人删掉自适应池化、直接把 `(N, 64, 4, 4)` 拉平，第一个 `Linear` 的输入特征数又是多少？

## 参考答案

**口述 1.** 高宽走 32、16、8、4。通道走到 128。自适应池化后每个通道剩 1 个数，拉平是 128。第一个全连接是 `Linear(128, 256)`，最后一个是 `Linear(256, 10)`，所以输出是 `(64, 10)`。

**口述 2.** 赋给 `self` 的层才会被模块登记成参数。优化器靠 `model.parameters()` 找到它们，`state_dict` 也靠这次登记来保存。写在 `forward` 里临时创建的层，每次前向都是一个新层，优化器碰不到，训练等于没训它。

**代码.**

```python
import torch
from torch import nn

model = CifarCNN()
fake = torch.rand(8, 3, 32, 32)
out = model(fake)
assert out.shape == (8, 10)

last = model.classifier[4]
print(last.weight.shape)  # torch.Size([10, 256])
```

`classifier` 是一个 `Sequential`，下标 0 是 Dropout，1 是第一层 Linear，2 是 ReLU，3 是 Dropout，4 才是输出层。

**思考.** 通道改成 16、32、64 之后，拉平长度变成 64，第一个全连接要改成 `Linear(64, 256)`，最后一层仍然是 `Linear(256, 10)`。如果删掉自适应池化、把 `(N, 64, 4, 4)` 直接拉平，特征数是 `64 * 4 * 4 = 1024`，第一个全连接就要写成 `Linear(1024, 256)`。这也是保留自适应池化的原因：分类头不必跟着空间尺寸改。
