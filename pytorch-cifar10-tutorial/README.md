# PyTorch 基础：用 CIFAR-10 图像分类学完整条流程

这是一套给学生讲的教程。读完并做完练习之后，你应该能不看笔记讲清三件事：

1. PyTorch 是什么，训练一个模型要经过哪些步骤。
2. 一个实际例子里，数据、模型、训练循环具体怎么写。
3. 做完之后怎么测评，看到什么现象就做什么优化，以及为什么这样想。微调是同一次任务里的下一步，不是另一门课。

## 贯穿全文的例子

CIFAR-10 图像十分类。每张图 32×32、3 个颜色通道，标签是 10 类里的一个：飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船、卡车。官方数据有 50000 张训练图、10000 张测试图。

前半部分从随机权重开始，自己写一个小卷积神经网络把它训起来。后半部分在这个同一任务上做测评和优化。小模型的验证准确率到顶之后，再换成 ImageNet 上预训练的 MobileNetV2 做微调。

## 建议怎么学

按课号往下读。每一课先看正文和代码，合上笔记回答课后练习，再对照参考答案。口述题要真的说出来。能答上课末那个问题，再进下一课。

环境：

```bash
pip install torch torchvision
```

有 NVIDIA GPU 时，PyTorch 会自动用它。没有 GPU 时，全部代码在 CPU 上也能跑通。完整的 CIFAR-10 训练在 CPU 上会比较慢，第 5 课安排了一个只用一个 batch 的检查，用来确认训练循环是通的。

## 学完要能背下来的一段话

PyTorch 是一个用 Python 写神经网络的库。我用它做 CIFAR-10 图像十分类：`DataLoader` 按批把图送进自己写的卷积神经网络，`CrossEntropyLoss` 衡量预测和标签的差距，Adam 根据反向传播得到的梯度更新权重。训练过程中我看验证集，决定要不要加数据增强、降低学习率、提前停止。最后用没有参与过任何决定的测试集报一次准确率。小模型到顶、或者自己的标注数据不多时，我会换 ImageNet 上预训练的 MobileNetV2，先只训练新的分类头，再用更小的学习率微调整个网络。

## 术语表

这些词后面每课都会用。先有一个印象即可，定义会在对应的课里展开。

| 词 | 在这个例子里的意思 |
| --- | --- |
| 张量 | PyTorch 里的多维数组，带形状、数据类型和所在设备。图像、权重、预测分数都是张量。 |
| 批次 batch | 一次同时送进网络的若干张图。本教程常用 64 张。 |
| 轮 epoch | 把训练集完整走一遍。 |
| logits | 模型最后一层吐出的 10 个原始分数，还没有变成概率。 |
| 损失 | 一个数，表示这一批预测离正确答案有多远。训练要让它变小。 |
| 梯度 | 损失对每个权重的变化率。它告诉优化器每个权重该往哪边挪。 |
| 学习率 | 每次按梯度更新时，步子的基本尺度。 |
| 训练集 | 用来改权重的图。 |
| 验证集 | 从训练图里留出来、不参与改权重的图。用来决定学习率、是否早停、一次改动留不留。 |
| 测试集 | 官方留出的 10000 张图。不参与任何决定，只在最后报一次成绩。 |
| 过拟合 | 训练集上很准，验证集上明显差一截。模型记住了训练图，而不是学会了能迁到新图上的规律。 |
| 微调 | 从别人已经训好的权重出发，在自己的数据上继续训练。 |
| 冻结 | 把一部分层的 `requires_grad` 关掉，优化器不更新它们。 |
